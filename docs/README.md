# Project Documents

This directory contains all the documents and manuals related to the project.  
It is organized into subdirectories according to document type and purpose.  

## Directory Structure

| Subdirectory | Description |
|--------------|-------------|
| `urs/`       | **User Requirement Specification (URS)**: Contains documents detailing the requirements and expectations from the user's perspective. |
| `drs/`       | **Design Requirement Specification (DRS)**: Contains documents specifying the design and technical requirements of the system based on the URS. |
| `ref/`       | **References**: Contains all papers, articles, and other reference materials used to compile the URS and DRS documents. This includes research papers, standards, and technical articles. |
| `manuals/`   | **Manuals**: Contains guides for running, installing, and compiling the project: <br> - `run.md` → How to run the software <br> - `install.md` → Installation instructions <br> - `compile.md` → Compilation instructions |
