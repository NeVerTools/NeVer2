# Compilation Manual

## Overview

This project is developed entirely in **Python** and does **not require a traditional compilation step**.
No source code translation or binary generation is needed prior to execution.

The project is composed of the following Python modules:
- **PyNeVer**
- **never2**

Both modules are interpreted directly by the Python runtime.

---

## Supported Architectures

The software is architecture-independent and can run on any platform that supports
a compatible Python ($\geq3.12$) interpreter.

The project has been tested on:
- **Windows 11**
- **Linux (Ubuntu 20.04 / 22.04)**

---

## Compilation Requirements

No compilation tools (e.g., compilers, build systems) are required.

All preparation steps related to environment setup and dependency installation
are described in **install.md**.
