This directory contains the source code for the project, organized into two main components:

- **PyNever/** – Contains the implementation of the core API, including the internal model representation, conversion logic, and related utilities.
- **NeVer2/** – Contains the graphical user interface (GUI) built on top of the PyNever API, providing visual editing, import/export functionalities, and interactive network manipulation.

Each component is structured as an independent module, but the GUI relies on PyNever for all backend operations.
