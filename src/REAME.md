This directory contains the extended version of the software along with its corresponding tests.  

## Directory Structure

| Subdirectory | Description |
|--------------|-------------|
| `main/`      | Contains the **extended software** source code. All new features and modifications to the original software are implemented here. |
| `tests/`     | Contains the **test suite** for the software, including unit tests, GUI tests, and integration tests to verify the functionality of the extended software. |
